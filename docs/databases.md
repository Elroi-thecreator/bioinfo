# Databases & Interactive Learning

Curated list of primary biological data repositories, reference catalogs, and interactive learning platforms.

---

## Primary Repositories & Genome Browsers

* **NCBI (National Center for Biotechnology Information):**
  * **GenBank / RefSeq:** Comprehensive nucleotide sequence archives and curated reference genomes.
  * **Sequence Read Archive (SRA):** Public repository for raw high-throughput sequencing data.
  * **GEO (Gene Expression Omnibus):** Functional genomics repository for microarray and RNA-seq data.

* **Ensembl & UCSC Genome Browser:**
  * Interactive multi-species genome visualization, coordinate navigation, and gene annotations (Gencode).

* **UniProt (Universal Protein Resource):**
  * Protein sequences, functional domain annotations, active sites, and post-translational modifications.

* **RCSB Protein Data Bank (PDB):**
  * 3D experimental structures of proteins, nucleic acids, and macromolecular assemblies.

---

## Interactive Learning Platforms

* **[Rosalind.info](https://rosalind.info/):**
  * Interactive platform for learning bioinformatics through problem-solving and algorithmic challenges. Covers Mendelian genetics, dynamic programming, tree reconstruction, and string indexing.

* **[Galaxy Training Network (GTN)](https://training.galaxyproject.org/):**
  * Free, comprehensive tutorials covering NGS analysis, variant calling, transcriptomics, proteomics, and metagenomics with pre-configured datasets.

* **[Bioconductor Tutorials](https://www.bioconductor.org/help/):**
  * Step-by-step documentation and vignettes for analyzing genomic data using R packages (`GenomicRanges`, `DESeq2`, `SingleCellExperiment`).
