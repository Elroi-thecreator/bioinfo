# Recommended Literature

A curated reading list spanning core algorithms, modern statistical methods, practical command-line skills, and NGS analysis.

---

## 1. Foundational & Practical Skills

### 📖 Bioinformatics Data Skills
* **Author:** Vince Buffalo (O'Reilly Media)
* **Target Audience:** Computational biology researchers & students.
* **Why Read It:** The definitive guide on reproducible research, Linux shell utilities (`grep`, `awk`, `sed`), Git version control, range-based genomic arithmetic (`GenomicRanges`), and high-performance workflow automation.
* **Key Focus Areas:** Unix command line, regular expressions, data integrity, Bioconductor basics, automation with Makefiles.

### 📖 The Biostar Handbook
* **Author:** István Albert
* **Target Audience:** Practitioners handling raw high-throughput sequencing data.
* **Why Read It:** A pragmatic, code-first manual covering real-world genomics problems, FASTQ/BAM file troubleshooting, and reproducible scripting.

---

## 2. Sequence Analysis & Algorithmic Theory

### 📖 Biological Sequence Analysis
* **Authors:** Richard Durbin, Sean R. Eddy, Anders Krogh, Graeme Mitchison
* **Target Audience:** Bioinformaticians, computer scientists, theoreticians.
* **Why Read It:** The fundamental reference for probabilistic sequence modeling. Covers dynamic programming algorithms (Needleman-Wunsch, Smith-Waterman), pairwise/multiple alignments, Hidden Markov Models (HMMs), and phylogenetic tree estimation.

### 📖 Bioinformatics Algorithms: An Active Learning Approach
* **Authors:** Phillip Compeau & Pavel Pevzner
* **Target Audience:** Programmers and students entering computational biology.
* **Why Read It:** Bridges theoretical computer science (graph theory, de Bruijn graphs, suffix trees) with biological problem-solving. Paired with interactive coding challenges on [Rosalind.info](https://rosalind.info).

---

## 3. Statistical Genomics & Modeling

### 📖 Modern Statistics for Modern Biology
* **Authors:** Susan Holmes & Wolfgang Huber (Cambridge University Press)
* **Target Audience:** Data scientists and researchers analyzing high-throughput assays.
* **Why Read It:** Practical statistical modeling for biological data: hypothesis testing, mixture models, clustering, RNA-seq differential expression, and dimension reduction (PCA, t-SNE, UMAP) using R and Bioconductor.
* **Open Access:** Freely available at [web.stanford.edu/class/bios221/book](https://www.huber.embl.de/msmb/).
