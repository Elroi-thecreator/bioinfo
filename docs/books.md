# Recommended Literature

A curated reading list spanning core algorithms, modern statistical methods, practical command-line skills, and NGS analysis.

---

## 1. Foundational & Practical Skills

### 📖 Bioinformatics Data Skills
* **Author:** Vince Buffalo (O'Reilly Media)
* **Target Audience:** Beginners to intermediate computational biologists.
* **Why Read It:** The definitive guide on reproducible data analysis, Linux shell wizardry, Git version control, range-based genomic arithmetic (GenomicRanges), and project architecture.
* **Key Topics:** Unix CLI, regex, data integrity, Bioconductor basics, automation with Makefiles.

### 📖 The Biostar Handbook
* **Author:** István Albert
* **Target Audience:** Practitioners handling raw high-throughput sequencing data.
* **Why Read It:** A pragmatic, task-oriented manual that focuses on solving real-world genomics problems using standard command-line utilities and scripting.

---

## 2. Sequence Analysis & Algorithmic Theory

### 📖 Biological Sequence Analysis
* **Authors:** Richard Durbin, Sean R. Eddy, Anders Krogh, Graeme Mitchison
* **Target Audience:** Advanced students, algorithm developers, theoreticians.
* **Why Read It:** The classic bible for probabilistic sequence modeling. Covers dynamic programming algorithms, pairwise/multiple alignments, Hidden Markov Models (HMMs), and phylogenetic tree estimation.

### 📖 Bioinformatics Algorithms: An Active Learning Approach
* **Authors:** Phillip Compeau & Pavel Pevzner
* **Target Audience:** Programmers and computer scientists entering biology.
* **Why Read It:** Beautifully bridges theoretical computer science (graph algorithms, dynamic programming, string indexing) with biological problems. Tightly coupled with the interactive [Rosalind.info](https://rosalind.info) coding challenges.

---

## 3. Statistical Genomics & Modeling

### 📖 Modern Statistics for Modern Biology
* **Authors:** Susan Holmes & Wolfgang Huber (Cambridge University Press)
* **Target Audience:** Bioinformaticians and data scientists analyzing high-throughput assays.
* **Why Read It:** Focuses on modern statistical inference, hypothesis testing, mixture models, clustering, and dimension reduction (PCA, t-SNE, UMAP) using R and Bioconductor.
* **Open Access:** Freely available online at [web.stanford.edu/class/bios221/book](https://www.huber.embl.de/msmb/).
